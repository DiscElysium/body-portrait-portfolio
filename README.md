# The Portrait of the Body

Public portfolio for an interaction-design project about AI-assisted sports films and personal expression.

Live site: https://discelysium.github.io/body-portrait-portfolio/

The five-page visual case study preserves the final portfolio layout. The site includes an accessible text version of each page, full-size viewing, two film demonstrations, three interview audio excerpts and a downloadable PDF.

Static HTML, CSS and vanilla JavaScript; no build service or API key is required. Publish the `main` branch root through GitHub Pages. All assets use relative paths.

Project photos, video frames and original cards belong to their respective creators. The cover illustration is AI-assisted editorial artwork. Barlow font licenses are included in this repository.
